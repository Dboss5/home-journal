# Homefront Backlink Plan

## Principle
Editorial backlinks only. Body copy, FAQ answers, and blog posts. Never nav, footer, or homepage heroes.

## Placement Rules
- Anchor text varies per placement — no exact duplicate
- UTM parameters on every link: `?utm_source=<brand>&utm_medium=referral&utm_campaign=<slug>`
- Do-follow for most, no-follow for ~30% (natural link profile)
- Never cluster two links on the same page unless the topic genuinely warrants both
- Never link twice from the same section

## UTM Reference
- Poolburg → `utm_source=poolburg`
- Supremacy → `utm_source=supremacy`
- Campaign slug = short, hyphenated description of the placement context
